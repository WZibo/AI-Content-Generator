# AI-Content-Generator

Use AI to help us generate the articles we want.

Technology stack used: NodeJS, Express, MongoDB/Mongoose, ReactJS, MVC Design Pattern, Authentication, Authorization

A full-stack web application using OpenAI's GPT-3.5-turbo model API to implement advanced text generation features. The application includes user authentication, payment processing, and content generation history.
Used React for the frontend, Node.js and Express for the backend, and MongoDB for data storage. Implemented Stripe API for secure payment processing. Ensured data security through token-based authentication. Integrated responsive navigation, a checkout form for payments, and a user-friendly interface for content generation and history tracking.
